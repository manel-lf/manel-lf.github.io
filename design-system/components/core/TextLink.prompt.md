The only inline link treatment: ink text over a hairline underline, both going accent on hover.

```jsx
<TextLink href="mailto:manellopez.alu@gmail.com">manellopez.alu@gmail.com</TextLink>
<TextLink mono onClick={reset}>Write another</TextLink>
```

Body copy never uses a coloured link at rest — the underline carries the affordance and the accent is the hover reward.
