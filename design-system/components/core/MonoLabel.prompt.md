The brand's second voice: 11px uppercase mono, wide tracking. Use for every eyebrow, date, meta line, kicker and stat label.

```jsx
<MonoLabel tone="muted">Prototypes and tooling</MonoLabel>
<MonoLabel tone="accent">Design systems</MonoLabel>
```

Never set mono type at body size or in sentence case — it exists to be small, uppercase and quiet next to Archivo. `tone="accent"` is only for bit-tile kickers and process-card indices.
