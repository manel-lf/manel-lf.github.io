Three metrics in a row — the spotlight card's proof, and the stat block inside journal posts.

```jsx
<StatRow stats={[
  { value: '6×', label: 'Day-0 activation' },
  { value: '6×', label: 'Faster time to first session' },
  { value: '2×', label: 'Day-1 retention' },
]} />
```

Values are relative multiples or plain words ("Same day", "Fewer", "Earlier"), never invented absolute figures. Three items; on mobile they become a 3-column grid.
